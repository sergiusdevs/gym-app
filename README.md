# Rutina · Culturismo y Progresión

Rutina de gimnasio personal, servida como página estática. El progreso (peso y repeticiones) se guarda en el `localStorage` del navegador, así que cada dispositivo/navegador empieza vacío y guarda solo localmente.

## Uso

Abre `index.html` directamente o visita la página publicada en GitHub Pages.

## Publicar en GitHub Pages

1. Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
2. La página quedará disponible en `https://<usuario>.github.io/gym-app/`.
